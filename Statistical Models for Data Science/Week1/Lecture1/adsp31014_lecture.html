1 Prerequisite

Here is a review of some prerequisite topics for this course.

1.1 Expectation

  • Expectation \(\mathbb{E}\) is always linear i.e. if \(X_1,\dotsc,X_n\) are any random variables and \(a_1,\dotsc,a_n\) are any constants, then \[\mathbb{E}(a_1 X_1+\dotsb+a_n X_n) = a_1\mathbb{E}(X_1) + \dotsb + a_n\mathbb{E}(X_n)\]
  • Special case #1: For linear (or affine) transformation of one random variable \(X\), \[\mathbb{E}(aX+b) = a\,\mathbb{E}(X) + b\]
  • If \(X\perp Y\) are independent, then \[\mathbb{E}(XY) = \mathbb{E}(X)\,\mathbb{E}(Y)\]

1.2 Variance, Standard Deviation

  • By definition, \[ \begin{align} \text{Var}(X) &= \mathbb{E}(X - \mathbb{E}(X))^2 = \mathbb{E}(X^2) - (\mathbb{E}(X))^2\geq 0\\ \text{SD}(X) &= \sqrt{\text{Var}(X)}\geq 0 \end{align} \]
  • If \(X\equiv c\) is a constant i.e. not random, then it does not vary i.e. \[\text{Var}(c) = 0 = \text{SD}(c)\]
  • If \(X_1,\dotsc,X_n\) are any random variables and \(a_1,\dotsc,a_n\) are any constants, then \[\text{Var}(a_1 X_1+\dotsb+a_n X_n) = a_1^2\text{Var}(X_1) + \dotsb + a_n^2\text{Var}(X_n) + 2 \sum_{1\leq i < j\leq n}a_i a_j\text{Cov}(X_i, X_j)\]
  • Special case #1: If \(X_1,\dotsc,X_n\) are independent, then all \(\text{Cov}(X_i, X_j)=0\) so \[\text{Var}(a_1 X_1+\dotsb+a_n X_n) = a_1^2\text{Var}(X_1) + \dotsb + a_n^2\text{Var}(X_n)\]
  • Special case #2: For two random variables \(X\) and \(Y\), \[\text{Var}(X + Y) = \text{Var}(X) + \text{Var}(Y) + 2\,\text{Cov}(X,Y)\] This means whether the “variance of the sum” is larger (or smaller) than the “sum of the variances” depends on if \(X\) and \(Y\) are positively (or negatively) correlated.
  • Special case #3: If \(Y\equiv b\) is a constant, then \(\text{Var}(b) = 0\) and \(\text{Cov}(X,b) = 0\) so \[ \begin{align} \text{Var}(aX+b) &= a^2\text{Var}(X)\\ \text{SD}(aX+b) &= |a|\,\text{SD}(X) \end{align} \] In other words, variance and standard deviation are not affected by translation by \(b\). But variance is in “squared unit of measurement” so it is scaled by \(a^2\) instead of just \(|a|\).
x <- rnorm(5)
var(x)
var(x + 10)
var(10 * x)
[1] 0.4091077
[1] 0.4091077
[1] 40.91077
  • If a random variable \(X\) has finite variance \(\text{Var}(X)<\infty\), then it will also have finite expectation \(\left|\mathbb{E}(X)\right| <\infty\). Conversely, if a random variable \(X\) does not have finite expectation i.e. \(\mathbb{E}(X)=\infty\) or \(-\infty\), then it will also have infinite variance \(\text{Var}(X)=\infty\).

1.3 Covariance, Correlation

  • By definition, \[ \text{Cov}(X,Y) = \mathbb{E}\left((X-\mathbb{E}(X))(Y-\mathbb{E}(Y))\right) = \mathbb{E}(XY)-\mathbb{E}(X)\mathbb{E}(Y) \] \[ \text{Corr}(X,Y) = \frac{\text{Cov}(X,Y)}{\text{SD}(X)\,\text{SD}(Y)}\in[-1,1] \]
  • Variance is always self-covariance i.e. \[ \begin{align} \text{Cov}(X, X) &= \text{Var}(X)\\ \text{Corr}(X,X) &= 1 \end{align} \]
  • If \(\text{Corr}(X,Y) = 1\), then \(X\) and \(Y\) are perfectly positively correlated. This only occurs when they are linearly related i.e. there exists some \(a>0\) and \(b\) such that \[X = aY + b\] Similarly, if \(\text{Corr}(X,Y) = -1\), then \(a < 0\).
  • If \(X\perp Y\) are independent random variables, then \[ \text{Cov}(X,Y) = \mathbb{E}(XY) - \mathbb{E}(X)\mathbb{E}(Y) = 0 \]
n <- 1000
x <- rnorm(n)
y <- rnorm(n)

plot(x, y)

  • But the converse is not true i.e. random variables can be uncorrelated but are still dependent. This is because covariance (and hence correlation) measures linear association only.
n <- 100
x <- seq(-1, 1, length.out = n)
y <- x^2 + 0.05 * rnorm(n)
y <- y - sum(x * y) / sum(x * x) * x # Residual of orthogonal projection

cor(x, y)
[1] -1.451212e-16

  • If \(Y\equiv c\) is a constant i.e. not random, then it is always independent of (and hence uncorrelated with) any other random variable \(X\). \[\text{Cov}(X,c) = 0 = \text{Corr}(X,c)\]
  • If \(X_1,\dotsc,X_n,Y_1,\dotsc,Y_m\) are any random variables and \(a_1,\dotsc,a_n,b_1,\dotsc,b_m\) are any constants, then \[\text{Cov}(a_1 X_1+\dotsb+a_n X_n,\,b_1 Y_1+\dotsb+b_m Y_m) = \sum_{i=1}^n\sum_{j=1}^m a_i b_j \text{Cov}(X_i,Y_j)\]
  • Special case #1: Since variance is self-covariance, all cases for variance above is a special case of this.
  • Special case #2: For 4 random variables, \[\text{Cov}(X+Y,U+V) = \text{Cov}(X,U)+\text{Cov}(X,V)+\text{Cov}(Y,U)+\text{Cov}(Y,V)\]
  • Special case #3: For positive linear (or affine) transformation with \(a > 0\) and \(c > 0\), \[\text{Corr}(aX+b, cY+d) = \text{Corr}(X,Y)\] In other words, correlation is not affected by translation or positive scaling.
x <- rnorm(10)
y <- rnorm(10)
cor(x, y)
cor(2 * x + 3, 4 * y + 5)

2 Modeling

  • We usually start with a set of \(n\) observed data points \(x_1,\dotsc,x_n\) or \(n\) pairs of data \((x_1,y_1),\dotsc,(x_n,y_n)\). Sometimes each data point \(x_i\) is not just a number but a \(d\)-dimensional vector \(\vec{x}_i=(x_{i1},\dotsc,x_{id})\in\mathbb{R}^d\) with \(d\) pieces of information.
  • Example: \(\vec{x}=\,\)(age, sex, race, height, weight, blood pressure) and \(y=\,\) cholesterol level
  • A model is a simplified assumption about the underlying structure of the observed data.
  • Modeling is the task of developing a suitable model that describes the observed data adequately. With this, we can:
    • Understand relationships within the data e.g. independence, low-dimensional
    • Perform clustering, dimension reduction, missing data imputation
    • Identify unusual observation / outlier / anomaly detection
    • Determine if a new observation is plausibly of the same kind
    • Predict / forecast the value of \(y\) for some unseen value of \(x\)

2.1 Parametric vs Non-Parametric

  • A parametric model is one in which the model can be parameterized (or completely described) by a fixed number of parameters \(\theta\) irrespective of the number \(n\) of observed data.
  • Example: Let \(x_1,\dotsc,x_n\in\{0,1\}\) be a sequence of observed coin tosses from a possibly unfair coin. We can model using a Bernoulli distribution \(\text{Bern}(p)\) with parameter \(\theta=p\) regardless of the number \(n\) of tosses.
  • Example: Let \(x_1,\dotsc,x_n\in\mathbb{R}\) be the observed cholesterol level values of \(n\) patients at a hospital. We can model using a normal distribution \(\mathcal{N}(\mu,\sigma^2)\) with \(2\)-dimensional parameter \(\theta=(\mu,\sigma^2)\).
  • Example: Linear regression model assumes a linear relationship \(y \approx \beta_0 + \beta_1 x_1 + \dotsb + \beta_d x_d\) between output \(y\) and a number of inputs \(x_1,\dotsc,x_d\) weighed by a fixed \(d+1\) number of parameters \(\beta_0,\dotsc,\beta_d\).
  • A non-parametric model is one in which the number of parameters of the model increases with the number of observed data.
  • Example: In machine learning, \(k\)-nearest neighbors \(k\)-NN algorithm whose model complexity is proportional to the number of observed data points, or local regression e.g. LOESS in which a separate regression model is fitted around each data point.
  • In this course, we focus on parametric model.

3 Linear Regression Part 1

  • Let \((\vec{x}_1,y_1),\dotsc,(\vec{x}_n,y_n)\) be \(n\) pairs of observed data points. In general, the objective of supervised machine learning modeling is to learn a mathematical relationship \(f\) between \(\vec{x}\)’s and target label \(y\)’s i.e. \[y = f(\vec{x}) + \epsilon\] In statistics, computer science, and machine learning literature and terminology:
    • \(\vec{x}\) is the explanatory variable / independent variable / predictor / covariate / input feature. In general, \(\vec{x}=(x_1,\dotsc,x_d)\in\mathbb{R}^d\) is a \(d\)-dimensional vector which represents \(d\) pieces of information.
    • \(y\) is the response variable / dependent variable / prediction / outcome / output.
    • \(f\) is the model. In practice, it can be any mathematical function e.g. linear formula, decision tree, neural net, etc.
    • \(\epsilon\) is the error / residual / noise that cannot be explained by the model \(f\).
  • If \(y\in\mathbb{R}\) is numerical / quantitative / continuous, then it is a regression task. On the other hand, if \(y\in\{c_1,\dotsc,c_k\}\) is a categorical / qualitative variable, then it is a classification task.

3.1 Linear Model

  • For linear regression, the model \(f\) represents a linear relationship between \(\vec{x}\) and \(y\) as follows: \[ y = \underbrace{\beta_0 + \beta_1 x_1 + \dotsb + \beta_d x_d}_{f(\vec{x})} + \epsilon\] Here \(\beta_0,\dotsc,\beta_d\) are the coefficients / parameters / weights of the model. They are unknown and to be estimated using the observed data.
  • The model equation \(f\) is “linear” because it involves a linear combination (in the sense of linear algebra) of the \(d\) explanatory variables \(x_1,\dotsc,x_d\).
  • Interpretation of coefficient \(\beta_j\): If \(x_j\) increases by \(+1\) unit to become \(x_j + 1\), then \(y\) should increase by \(+\beta_j\) units.
  • If \(d = 1\) i.e. only one explanatory variable, then it is simple linear regression. Otherwise, if \(d \geq 2\), then it is multiple linear regression.
  • Example: The following model equation is still linear if we consider it as a relationship between \(y\) and some new input features \(x_3 = \log{x_1}\), \(x_4 = (x_2)^2\), and \(x_5 = x_1 x_2\). \[y = \beta_1 \underbrace{\log{x_1}}_{x_3} + \beta_2 \underbrace{(x_2)^2}_{x_4} + \beta_3 \underbrace{x_1 x_2}_{x_5} + \epsilon\]
  • Example: The following model equation between \(y\) and \(x\) cannot be rewritten in the linear form so it is not a linear model. \[y = \beta_0 + \beta_1 x^{\beta_2} + \epsilon\]

3.2 Simple Linear Regression, Ordinary Least Squares

  • How do we find the optimal \(\beta_0^*,\dotsc,\beta_d^*\) parameters? Let’s start with simple linear regression.
x <- c(0.4, 0.8, 1.2, 1.7, 2.1)
y <- c(2, 5, 4.3, 4.2, 8)

  • Model equation is \[ y = \underbrace{\beta_0 + \beta_1 x}_\text{line}+\epsilon\] with unknown intercept \(\beta_0\) and slope \(\beta_1\) parameters for the line.
  • Let’s measure the goodness-of-fit of any particular line \(y = \beta_0+ \beta_1 x\) based on the mean squared error MSE metric \[\text{MSE} = \frac{1}{n}\sum_{i=1}^n \big(\underbrace{y_i - (\overbrace{\beta_0 + \beta_1 x_i}^{\text{predicted } \hat{y}_i})}_{\text{residual }r_i\text{ or error }e_i}\big)^2\] on the observed data. Here:
    • \(\beta_0 + \beta_1 x_i\) is the fitted / predicted value (denoted by \(\hat{y}_i\)) along the line for the \(i^\text{th}\) data point \(x_i\).
    • \(y_i - \hat{y}_i\) is the residual (denoted by \(r_i\)) or error (denoted by \(e_i\)) of the prediction. In the plot above, it corresponds to the vertical discrepancy between the observed true value / ground truth \(y_i\) and the line.
    • MSE is the total discrepancy over the entire observed data set.
  • Why do we use MSE? As an example, isn’t it simpler and more intuitive to use mean absolute error MAE \[\text{MAE} = \frac{1}{n}\sum_{i=1}^n \big|y_i - (\beta_0 + \beta_1 x_i)\big|\] instead? The main reason is that a quadratic function \(f(x)=x^2\) is differentiable but an absolute value function \(f(x)=|x|\) is not.
  • If a residual \(r_i\) has large (positive or negative) value, then its squared value \(r_i^2\) is even larger. Therefore, MSE is easily impacted by an outlier. As a result, linear regression is not very robust against outliers.
  • To find the optimal line and its intercept \(\beta_0^*\) and slope \(\beta_1^*\), the ordinary least squares OLS method seeks to minimize the MSE loss / cost / objective function \[\min_{\beta_0,\beta_1}\,\underbrace{\frac{1}{n}\sum_{i=1}^n \big(y_i - (\beta_0 + \beta_1 x_i)\big)^2}_\text{MSE}\] (In modern machine learning paradigm, this is a common approach to learn a model by optimizing a metric over a training data set.)
  • By using calculus to differentiate the MSE with respect to its variables \(\beta_0\) and \(\beta_0\) and applying the first-order condition, we obtain the optimal slope parameter \[\beta_1^* = \frac{\sum_{i=1}^n (x_i-\bar{x}_n)(y_i-\bar{y}_n)}{\sum_{i=1}^n (x_i-\bar{x}_n)^2} = \frac{\text{Cov}(X,Y)}{\text{Var}(X)} = \text{Corr}(X,Y)\frac{\text{SD}(Y)}{\text{SD}(X)}\] and intercept parameter \[\beta_0^* = \bar{y}_n - \beta_1^* \bar{x}_n\] Note those are sample \(\text{Cov}(\dotso)\), \(\text{Var}(\dotso)\), and \(\text{SD}(\dotso)\).
  • In R, use built-in lm() function to fit linear regression model.

3.4 Coefficient of Determination \({\small R^2}\)

  • The simplest linear regression model is the null model with only the intercept parameter \(\beta_0\) and no explanatory variable i.e. \[y = \beta_0 + \epsilon\] In this case, the optimal intercept parameter \(\beta_0^* = \bar{y}_n\) is simply the sample mean of the response values. As a result, the fitted / predicted value \(\hat{y}_i = \beta_0^* = \bar{y}_n\) is a constant. The total error of this constant model on the observed data is \[SS_\text{total} = \sum_{i=1}^n (y_i - \bar{y}_n)^2\] This is called the total sum of squares. It represents the total amount of variation within the response values \(y_1,\dotsc,y_n\).
  • When we use a more sophisticated linear regression model with one or more explanatory variables i.e. \[y = \beta_0 + \beta_1 x_1 + \dotsb + \beta_d x_d + \epsilon\] it can fit the observed data better i.e. \(y_i \approx \hat{y}_i\) so the amount of error of this model \[SS_\text{error} = \sum_{i=1}^n (y_i - \hat{y}_i)^2 < SS_\text{total}\] is smaller than \(SS_\text{total}\). This is called the residual / error sum of squares (sometimes denoted by \(SS_\text{res}\)). It represents the amount of variation in the response values that is unexplained by the explanatory variables.
  • At the same time, each fitted value \(\hat{y}_i\) is likely farther away from the overall mean \(\bar{y}_n\). So the quantity \[SS_\text{reg} = \sum_{i=1}^n (\hat{y}_i - \bar{y}_n)^2 > 0\] increases. This is called the model / regression sum of squares (sometimes denoted by \(SS_\text{model}\)).
  • Fact: We have the exact decomposition \[\underbrace{\sum_{i=1}^n (y_i - \bar{y}_n)^2}_{SS_\text{total}} = \underbrace{\sum_{i=1}^n (\hat{y}_i - \bar{y}_n)^2}_{SS_\text{reg}} + \underbrace{\sum_{i=1}^n (y_i - \hat{y}_i)^2}_{SS_\text{error}}\] (This is only true when the linear regression model has an intercept parameter.)
  • This motivates us to measure the goodness-of-fit of a linear regression model based on the coefficient of determination \[R^2 = \frac{SS_\text{reg}}{SS_\text{total}} = 1 - \frac{SS_\text{error}}{SS_\text{total}}\in[0,1]\] (The definition of \(R^2\) is slightly different for linear regression model without the intercept term. See R’s ?summary.lm documentation. These two definitions are not comparable.) It represents the percentage / proportion of variation in the response variable that can be explained by the explanatory variables of the model.
x <- c(0.4, 0.8, 1.2, 1.7, 2.1)
y <- c(2, 5, 4.3, 4.2, 8)
model <- lm(y ~ x)

# Compute various sums of squares
ss.total <- sum((y - mean(y)) ^ 2)
ss.reg <- sum((fitted(model) - mean(y)) ^ 2)
ss.error <- sum((y - fitted(model)) ^ 2) # Same as deviance(model)

c(ss.total, ss.reg, ss.error) # SST = SSR + SSE

# Coefficient of determination R^2
cor(y, fitted(model)) ^ 2
ss.reg / ss.total # SSR / SST
1 - ss.error / ss.total # 1 - SSE / SST

  • Note \(0 < R^2 < 1\) is “normalized” in the sense that \(SS_\text{reg}\) and \(SS_\text{error}\) are benchmarked against \(SS_\text{total}\) of the baseline constant model with only the intercept.
  • If \(R^2 \approx 1\), then \(SS_\text{reg}\approx SS_\text{total}\) and \(SS_\text{error}\approx 0\) so the model explains the response variable well. If \(R^2 = 1\), then \(SS_\text{error}= 0\) so all predictions are perfect i.e. \(y_i = \hat{y}_i\) with no error or residual.
  • If \(R^2 = 0\), then the linear regression model does as poorly as the constant model with only the intercept.
  • How is \(R^2\) related to MSE? Since \(\text{MSE} = SS_\text{error} / n\) and \(SS_\text{total}=c\) is a constant that does not depend on any particular linear regression model, we have \[R^2 = 1 - \frac{SS_\text{error}}{SS_\text{total}} = 1 - \frac{\text{MSE}\times n}{c}\] So \(R^2\) and MSE are equivalent metrics that are related monotonically i.e. if one increases, then the other one decreases.
  • Fact: For linear regression model with intercept, we have \[R^2 = \text{Corr}(Y, \hat{Y})^2\] Note this is sample \(\text{Corr}(...)\).

3.5 Multicollinearity

  • In multiple linear regression, with many explanatory variables \(\vec{x} = (x_1,\dotsc,x_d)\) in the model to explain the response variable \(y\), there is a higher chance that some of these \(d\) explanatory variable are correlated. In this case, \(\vec{x}\in\mathbb{R}^d\) might not represent \(d\) separate pieces of information i.e. there is some redundancy. This is called multicollinearity. (Note this concept is focused on the explanatory variables \(x_1,\dotsc,x_d\) themselves and has nothing to do with the response variable \(y\).)
  • If two explanatory variables \(x_1\) and \(x_2\) are perfectly correlated i.e. \(\text{Corr}(x_1, x_2) = 1\), then their roles are exchangeable. For example, if \(x_1 = x\) and \(x_2 = 4\,x\), then the model equation \[y = 4 \,x_1 + 0\,x_2 = 0\, x_1 + 1\, x_2 = 2\, x_1 + 0.5\,x_2\] can be represented in (infinitely) many ways. The model is non-identifiable because of the non-uniqueness of the model parameters. (This is exactly the same as the concept of linear dependence of vectors in linear algebra.)
x1 <- c(0.4, 0.8, 1.2, 1.7, 2.1)
y <- c(2, 5, 4.3, 4.2, 8)

x2 <- 2 * x1 # Corr(x1, x2) = 1

  • Multicollinearity makes numerical computation unstable. Parameter estimation becomes very sensitive i.e. a small change in an explanatory variable \(x_i\) might result in a large change in the values of (more than one) model parameters. Consequently, the model has poor explainability because a \(+1\) unit increase in an explanatory variable \(x_i\) does not imply a \(+\beta_i\) unit increase in the response variable \(y\) anymore. (Part of the reason is because a change in \(x_i\) will also imply a change in other highly correlated explanatory variables so the scenario of “\(+1\) unit in \(x_i\) while having all else being the same” does not hold.)

  • How to detect general multicollinearity?
    1. For each explanatory variable \(x_i\), we fit a multiple regression model with \(x_i\) as the response variable to see how much it can be explained by the other explanatory variables \(x_1,\dotsc,x_{i-1},x_{i+1},\dotsc,x_d\).
    2. If the linear regression model \(R^2\) is high, then the model has found a linear combination of the other explanatory variables that together is highly (in fact, highest) correlated with \(x_i\).
    3. Compute the variance inflation factor VIF \[\text{VIF} = \frac{1}{1-R^2}\in[1,\infty)\]
    4. In practice, if \(\text{VIF}>5\) i.e. \(R^2 > 0.8\) or correlation \(|R| > 0.89\), then there is strong evidence of multicollinearity. In this case, we should consider omitting the explanatory variable \(x_i\) from the modeling.
(r2 <- summary(lm(x3 ~ x1 + x2))$r.squared)
(vif <- 1 / (1 - r2))

If two explanatory variables are highly correlated with each other, then they would both have high VIF values. But it doesn’t mean you should simply omit both variables from modeling. Perhaps you need to keep one of them.

3.6 Polynomial Regression

  • If the relationship between the observed response \(y\) and an explanatory variable \(x\) looks like a higher-degree polynomial instead of a straight line, then we could do feature engineering to construct additional explanatory variables for the higher-order terms e.g.  \[x_1 = x,\,x_2 = x^2,\,x_3=x^3,\,\dotsc,\,x_p= x^p\] The resulting linear regression model \[y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \dotsc + \beta_p x_p +\epsilon\] is essentially fitting a \(p^\text{th}\) degree polynomial curve to the original observed data \(x\) and \(y\) i.e. \[y = \beta_0 + \beta_1 x + \beta_2 x^2 + \dotsc + \beta_p x^p +\epsilon\]
  • Such polynomial regression is still considered a “linear” regression model in the sense that it involves a linear combination of the explanatory variables. It just happens that these explanatory variables \(x_1,\,x_2,\,\dotsc\) are related to each other.
x <- c(-0.47, -0.26, 0.15, 0.82, -0.6, 0.80, 0.89, 0.32)
y <- c(0.25, -0.02, 0.07, 0.74, 0.41, 0.60, 0.94, 0.14)

plot(x, y, type = 'p')
abline(lm(y ~ x), col='red')

model <- lm(y ~ x + I(x ^ 2))

  • Why? If we apply an affine transformation \(x\mapsto x+1\) to transform the explanatory variable, then the relationship between \(y\) and \(x\) becomes \[y = \beta_2 (x + 1)^2 + \epsilon = \beta_2 + 2 \beta_2 x + \beta_2 x^2 + \epsilon\] The lower-degree terms (i.e. intercept and linear terms) re-appear. Therefore, in order to preserve the invariance property of linear regression model with respect to affine transformation, it is best practice to keep all lower-degree terms \(x^0=1,\,x,\,x^2,\dotsc,\,x^{p-1}\) up to the highest degree \(x^p\) of our polynomial regression. (This continues to hold when we consider higher-order interaction terms later.)
