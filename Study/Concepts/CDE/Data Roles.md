# Data Roles
**In one line:** Data engineers build the data platform, data scientists build models, and data analysts answer business questions. All three depend on good pipelines.

**In plain words:** The data engineer designs, builds and runs the systems that move and store data reliably at scale. They own the pipelines, storage, quality and monitoring. The data scientist uses that data to train models and run experiments. The analyst queries the cleaned data and builds dashboards. On real teams these roles blur, and they work together.

**Terms**
| Role | Does | Core skills |
|---|---|---|
| Data engineer | builds and maintains the platform and pipelines | SQL, Python, cloud, DevOps, distributed systems |
| Data scientist | trains models, extracts statistical insight | statistics, ML, experimentation |
| Data analyst | queries curated data for business answers | SQL, BI tools, dashboards |

**Key points**
- The data engineer bridges raw sources and downstream users (analysts, scientists, apps).
- They own pipelines, storage, quality and observability.
- "All three roles depend on well-engineered, trustworthy data pipelines."

**Memorize vs. look up:** Memorize what each role produces.
