# Data Science Pipeline
**In one line:** The course's five-stage roadmap for a consulting project: Define → Collect → Model → Rationalize → Deploy.

**In plain words:** First understand the business problem and write it down clearly (Define). Then gather and explore the data (Collect). Build and test models that fit the problem (Model). Make the business case: costs, benefits, risks and a timeline (Rationalize). Finally roll it out with a roadmap, documentation and monitoring (Deploy). Every client case in the course (McDonald's, Verizon) follows this path.

**Terms**
| Stage | What happens |
|---|---|
| Define | background, requirements, scope, problem statement, estimated value |
| Collect | identify internal and external data, obtain, clean, explore (EDA) |
| Model | research, select, build and evaluate models |
| Rationalize | cost/benefit (NPV, LTV), risks and mitigation, timeline, pilot, team |
| Deploy | roadmap (people, process, technology), execute, document, manage change, operate |
| EDA | exploratory data analysis: describe, question, understand the data |
| LTV | customer lifetime value |

**Key points**
- **Collect, 5 steps:** assess data and objectives → identify sources, formats, volume → define purpose and comply with laws (GDPR, HIPAA) → automate and check relevance → test, document, secure.
- **Expand the data universe:** internal and external, purchased, experiments, competitive benchmarks.
- **Ethics:** collect only what's needed, get consent, anonymize, guard against bias, control access.
- **Model:** match the problem to the solution type (supervised → regression or classification; unsupervised → clustering or association; reinforcement → control), and consider the client's analytic maturity.
- **Deploy:** integration, automation, testing; documentation (technical, user manuals, maintenance, compliance); operations (monitoring, tuning, security, disaster recovery).

**Memorize vs. look up:** Memorize the five stages in order and one task each.
