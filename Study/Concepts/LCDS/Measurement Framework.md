# Measurement Framework
**In one line:** A six-level "causality chain" that links a data project's spending all the way up to company results.

**In plain words:** Executives ask, "What did we get for this data spending?" The answer is a chain. An initiative (buy a data-quality tool) improves the data (fewer duplicate customers), which improves analysis (better models), which improves processes (fewer returns), which improves performance (customer retention), which shows up in organization results (revenue, market share). Measure each link so you can show the cause and effect.

**Terms**
| Term | Means |
|---|---|
| Causality chain | cause-and-effect path from initiative to business outcome |
| Initiative metrics | progress (capability, tools, skills) and adoption (business units, functions) |
| Data metrics | data quality and delivery |
| Analysis metrics | model and report performance, usage, users |
| Process metrics | efficiency and effectiveness of changed processes |
| Performance / capability metrics | demand, supply and support-service indices |
| Organization metrics | financial (income, ROE, margin) and non-financial (satisfaction, market share) |
| Infonomics | treating information as an asset with economic value |

**Key points**
- Six levels: **1** Initiative → **2** Data → **3** Analysis → **4** Process → **5** Performance → **6** Organization.
- Levels 1–3 are defined by Data & Analytics; levels 4–6 are defined by the business.
- Links don't all have to be numeric or cover every level.
- Linking to an organizational metric: find it on the executive scorecard → find the processes that drive it → design data metrics that feed those processes.
- Analytics types: descriptive (what happened?), diagnostic (why?), predictive (what will happen?), prescriptive (what should we do?).
- A model's value is business impact (profit gained, losses avoided, risk, cash flow, market share), not accuracy or F1 score.

**Example:** Address-quality tool ($25K) → 40% better address accuracy → fewer failed deliveries → returns down 60% → customer satisfaction up.

**Memorize vs. look up:** Memorize the six levels in order and "value = business impact".
