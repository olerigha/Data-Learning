# Leading vs Lagging Indicators
**In one line:** Lagging indicators show results after the fact; leading indicators measure the activities that drive those results, giving early warning.

**In plain words:** Revenue and customer satisfaction are lagging: by the time they move, it's too late to change them. Leading indicators track the earlier actions that cause them, like on-time delivery or order accuracy, so you can steer in real time. You need both, linked: the leading ones say *how* you'll get there, the lagging ones say *whether* you did.

**Terms**
| Term | Means |
|---|---|
| Lagging indicator | measures the end outcome; backward-looking |
| Leading indicator | measures drivers that come before the outcome; predictive |
| KPI | Key Performance Indicator (often leading in this framing) |
| KRI | Key Result Indicator (lagging) |
| Baseline / target | where you start / where you aim to be |

**Key points**
- Link each leading indicator to the lagging one it informs (causality chain).
- Define them cross-functionally so everyone uses the same definitions.
- Set a standard definition, baseline and target, and make sure the data exists to measure it.
- Revisit them regularly to stay relevant.
- Process examples: leading = on-time delivery, defects, time-to-market; lagging = click-through rate, customer and employee satisfaction.
- MIT Sloan / BCG 2024: 60% of leaders say their KPIs need improvement; only 34% use AI to create new KPIs.

**Memorize vs. look up:** Memorize the definitions and "you need both, linked".
