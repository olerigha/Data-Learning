# Pyramid Principle
**In one line:** Lead with the main answer, then group the supporting points beneath it, so the story makes sense from the top down.

**In plain words:** Executives want the conclusion first. Put your one key message at the top of the pyramid, a few grouped reasons under it, and the evidence under those. In a deck, the slide **titles** read in order should tell the whole story by themselves (horizontal logic). Everything on each slide should back up that slide's title (vertical logic).

**Terms**
| Term | Means |
|---|---|
| Pyramid Principle | Barbara Minto's method: answer first, then grouped support |
| Storyline title | a slide title that states a message, not a topic ("Returns fell 60%", not "Returns") |
| Horizontal logic | reading all the titles in order tells the story |
| Vertical logic | each slide's body supports its own title |
| Takeaway | optional callout of the slide's key message |

**Key points**
- Build it bottom-up (group the details into themes) or top-down (start from the answer); then test it.
- Story steps: list objectives → state all key messages → group them → order the groups into a simple flow.
- Test: read only the titles. If the story doesn't hold, fix the titles before the slides.

**Example:** Titles like "Cosigned loans rose from 75% to 90%" → "Lenders can target students without cosigners" → "A 22-week plan delivers it" form a story on their own.

**Memorize vs. look up:** Memorize answer-first, horizontal logic and vertical logic.
