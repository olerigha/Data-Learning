# Week 1: Introduction to Cloud Data Engineering

## Overview

Week 1 establishes the foundational concepts of data engineering. It covers the data engineering lifecycle, data structures, computing trends, cloud computing overview, Moore's Law, Infrastructure as Code (IaC) principles, and multi-cloud strategy.

## Core Topics

1. **Data Engineering Foundations**
   - The role of the data engineer in the modern data stack.
   - The data engineering lifecycle: Ingest &rarr; Store &rarr; Transform &rarr; Serve &rarr; Govern.
   - Data types: Structured (tabular/relational), Semi-structured (JSON/Avro/Parquet), and Unstructured (text/media).
   - Data provenance, lineage, and data governance fundamentals.

2. **Computing Trends & Cloud Overview**
   - Computing trends: Moore's Law, hardware commoditization, and the transition from on-premises to cloud.
   - Cloud computing overview: Economies of scale, decoupled compute and storage, and elastic resource management.
   - Infrastructure as Code (IaC) concepts and multi-cloud vs. single-cloud strategy.
